# Stuff-LSIRC

Repositório de material de estudo para o curso de **Licenciatura em Segurança Informática em Redes de Computadores (LSIRC)**.

## Sobre o Repositório

Este espaço tem como objetivo centralizar apontamentos, resumos, exercícios práticos, guiões e outros recursos relevantes para as diversas unidades curriculares do curso.

## Contribuições

As contribuições são muito bem-vindas! Se tiver material que considere útil ou quiser corrigir/melhorar algum documento existente, sinta-se à vontade para abrir uma *Issue* ou enviar um *Pull Request*.
