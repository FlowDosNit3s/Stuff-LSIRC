📌 1. Mapeamento do Modelo de Domínio (Ajuda Humanitária)

  • IInstitution: Entidade agregadora que gere caixas e veículos.
  • AidBox: Caixa de recolha de bens associada a uma zona. Contém contentores.
  • Container: Contentor para um tipo de bem (ItemType), com capacidade e medições.
  • Measurement: Registo de leitura (valor numérico e data).
  • Vehicle / RefrigeratedVehicle: Veículos de transporte.
  • Route / Strategy: Criação e validação de rotas otimizadas.

📌 2. Padrões Algorítmicos em Arrays Nativos (Sem Collections)

Compactação de Array (Remover Nulos):

public Container[] getContainers() {
    int count = 0;
    for (int i = 0; i < numberOfContainers; i++) {
        if (containers[i] != null) count++;
    }
    Container[] result = new Container[count];
    int idx = 0;
    for (int i = 0; i < numberOfContainers; i++) {
        if (containers[i] != null) result[idx++] = containers[i];
    }
    return result;
}
