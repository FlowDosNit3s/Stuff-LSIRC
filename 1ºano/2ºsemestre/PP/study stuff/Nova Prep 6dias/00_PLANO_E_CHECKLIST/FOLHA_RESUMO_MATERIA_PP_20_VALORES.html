3. Passagem de Argumentos em Java (Pass-by-Value)

Em Java a passagem é exclusivamente por valor. Nos primitivos copia-se o valor. Nos objetos copia-se o endereço de memória (referência). Reatribuir a variável no método não afeta fora; chamar métodos modificadores altera o estado na Heap.

public static void testar(int x, Container c) {
    x = 99;                 // Não afeta a variável original
    c.setCapacity(500.0);   // Altera o estado do objeto na Heap!
}

4. Identidade vs Igualdade (== vs equals())

== compara se apontam para a mesma posição de memória Heap. equals() compara igualdade lógica de conteúdo.

@Override
public boolean equals(Object obj) {
    if (this == obj) return true;
    if (obj == null || !(obj instanceof AidBox)) return false;
    AidBox other = (AidBox) obj;
    return this.code != null && this.code.equals(other.getCode());
}

5. Tratamento de Exceções (Checked vs Unchecked)

  • Checked Exceptions: Subclasses de Exception (sem RuntimeException). O compilador obriga a tratar com try-catch ou declarar com throws.
  • Unchecked Exceptions: Subclasses de RuntimeException. Erros de lógica/bugs. O compilador não exige declaração.
  • Bloco finally: Executa sempre (mesmo com return no try/catch).

6. Algoritmia de Arrays Nativos sem Collections Framework

⚠️ FATOR CRÍTICO: É proibido usar ArrayList ou HashMap no exame. Usar exclusivamente Tipo[].

Compactação de Arrays (Remover Nulos):

public Container[] getContainers() {
    int count = 0;
    for (int i = 0; i < this.numberOfContainers; i++) {
        if (this.containers[i] != null) count++;
    }

    Container[] result = new Container[count];
    int idx = 0;
    for (int i = 0; i < this.numberOfContainers; i++) {
        if (this.containers[i] != null) {
            result[idx] = this.containers[i];
            idx++;
        }
    }
    return result;
}
