Objetivo: Preparação a 100% para alcançar a nota máxima (20 Valores) no Exame de Época Especial.

🎯 A DICA DE OURO DO PROFESSOR PARA O EXAME:

"O exame é exatamente a aplicação prática sobre o tema do Trabalho Prático (TP), mas com INTERFACES DIFERENTES para implementar!"

  1. O domínio de negócio é SEMPRE o mesmo do TP (Ajuda Humanitária, AidBox, Container, Measurement, Vehicle, RefrigeratedVehicle, Route, Strategy).
  2. Na folha de exame, o professor altera os contratos das interfaces.
  3. O padrão de resolução é 100% FIXO (Parte 1: 6,0v Teoria | Parte 2: 14,0v Prática).

📌 Estrutura do Exame de PP (2 Horas / 120 Minutos)

Parte Tipo de Avaliação Cotação Foco do Conteúdo
Parte 1 4 Perguntas Teóricas de Resposta Aberta 6,0 Valores (1,5v cada) Conceitos de POO em Java, semântica, mecanismos da linguagem e boas práticas.
Parte 2 4 Perguntas Práticas de Programação Java 14,0 Valores (3v + 2v + 4v + 5v) Desenvolvimento de código sobre o modelo do TP com interfaces fornecidas.

🚫 PROIBIÇÃO DE JAVA COLLECTIONS FRAMEWORK:

É estritamente proibido utilizar classes do Java Collections Framework (ArrayList, HashMap, LinkedList, etc.). Deve utilizar-se exclusivamente arrays nativos (Tipo[]).
